# Итоговые семестровые работы

В каждом семестре студент выполняет один проект, выбирая один из шести индивидуальных вариантов соответствующей работы. Вариант дополняет общий обязательный минимум и не заменяет его. Каждая работа рассчитана ориентировочно на 20 академических часов самостоятельной работы. При недостатке времени преподаватель сокращает расширение, сохраняя одинаковый обязательный минимум для группы.

Студент сдаёт исходный код, собственные тесты, README с запуском и краткий отчёт 3–5 страниц: контракт, алгоритм, проверки, ограничения. Архив проекта должен запускаться после распаковки в чистую папку. Не включать виртуальную среду, кэши и личные данные.

Каталог teacher содержит преподавательские эталоны и ответы: его не следует автоматически выдавать группе вместе с заданиями. Для выдачи студентам подготовлен отдельный архив без teacher. В эталонном комплекте tests/test_projects.py импортирует teacher.complex_reference и teacher.matrix_reference. Для проверки студенческой реализации скопировать тесты в папку проекта, заменить эти два импорта на semestr_task и matrix_ops соответственно. Для проверки одного семестра удалить импорт и класс тестов другого семестра. Требуемые имена функций приведены в спецификациях. Публичные тесты — стартовый набор, студент добавляет проверки своего варианта и интерфейса.

## Общая рубрика проекта

| Критерий | Баллы | Наблюдаемое основание |
|---|---:|---|
| Обязательные операции | 35 | Правильные результаты обычных и граничных примеров, пропорционально числу выполненных операций |
| Контракт и ошибки | 15 | Неверная форма, типы, деление на ноль или несовместимость размерностей обрабатываются как оговорено |
| Тесты | 15 | Независимые ожидаемые ответы, границы, свойства, регрессионные случаи |
| Структура и воспроизводимость | 10 | Отдельные вычисления и интерфейс, команды запуска, сохранение входов |
| Индивидуальный вариант | 10 | Заявленное расширение и тесты его контракта |
| Личная защита | 15 | Объяснение 5, трассировка 5, небольшое изменение с проверкой 5 |
| Всего | 100 | В семестровый рейтинг переносится 40% результата |

Для допуска к защите достаточно работающего минимального сценария и предъявления собственных тестов. Защита включает 5 минут демонстрации и 5 минут вопросов. При непонимании ключевого фрагмента предложить повторную индивидуальную защиту после доработки, а не подменять оценку предположением об авторстве.

## Готовые публичные проверки для студента

В этой папке есть отдельные test_complex.py и test_matrix.py. Скопируйте нужный файл рядом с semestr_task.py или matrix_ops.py и выполните `python3 test_complex.py` либо `python3 test_matrix.py`. Эти файлы не требуют каталога teacher. До написания студентом своего модуля сообщение ModuleNotFoundError ожидаемо: это не готовые решения.
