# Семестровая работа 2 Матричная библиотека

## Назначение

Разработать модуль matrix_ops.py и консольный запуск операции над матрицами из JSON. Сохраняется математическая направленность исходного курса, но неоднозначное «деление матриц» исключено. Все операции реализуются самостоятельно на списках и стандартной библиотеке. NumPy и готовые реализации линейной алгебры в студенческом ядре не используются.

## Вход и ошибки

Матрица — точный тип list, от 1 до 20 строк, каждая строка — list одинаковой длины от 1 до 20. Числа имеют точный тип int или float, конечны, |x|≤1000. bool запрещён. Пустые и рваные матрицы недопустимы. При неверном входе или несовместимой форме функция поднимает ValueError. Функции сохраняют исходные списки и возвращают новые результаты. Печать и файловый ввод находятся вне ядра.

## Восемь обязательных операций

| Функция | Контракт |
|---|---|
| add(A,B) | Поэлементная сумма, формы совпадают |
| subtract(A,B) | Поэлементная разность A-B, формы совпадают |
| matmul(A,B) | Матричное произведение, число столбцов A равно числу строк B |
| transpose(A) | Матрица n×m для входа m×n |
| determinant(A) | Только квадратная, метод исключения с выбором опоры, знак обменов учтён |
| rank(A) | Количество опор после исключения, допускается прямоугольная форма |
| norm1(A) | Максимум по столбцам суммы модулей элементов |
| count_nonzero(A) | Число элементов, точно не равных 0; здесь eps не применяется |

Для determinant и rank используется абсолютный порог eps=1e-9: элемент с модулем ≤eps считается нулевым. Опору выбирают по максимальному модулю в доступной части столбца. Определитель после исключения равен произведению ненормированных опор с поправкой на обмены. Если опора не найдена, determinant возвращает 0.0. Для rank такой столбец пропускается, поиск продолжается в следующем. Оценка ранга является численной, зависит от порога и не заменяет точную символьную алгебру. На защите требуется показать пример чувствительности к масштабу.

В проверках результатов использовать rel_tol=1e-7 и abs_tol=1e-7. Для ранга ожидается точное целое при указанном eps. Базовые тесты используют хорошо обусловленные малые целочисленные матрицы. Пограничные вещественные случаи обсуждаются отдельно и не оцениваются по неоговорённому эталону.

## Интерфейс и данные

Запуск: python3 main.py input.json output.json. Вход содержит operation и A, а для бинарной операции также B. Пример: {"operation":"matmul","A":[[1,2]],"B":[[3],[4]]}. Выход: {"result":[[11]]}. Неизвестная операция или неверные данные дают {"error":"понятное сообщение"} и ненулевой код завершения. Входной и выходной путь должны различаться. Отсутствующий файл и неверный JSON обрабатываются явно. Успешный результат записывается в UTF-8 JSON.

## Приёмочные примеры

- transpose([[1,2,3],[4,5,6]]) → [[1,4],[2,5],[3,6]].
- add([[1,2]],[[3,4]]) → [[4,6]]. subtract → [[-2,-2]].
- matmul([[1,2]],[[3],[4]]) → [[11]].
- determinant([[0,2],[3,4]]) → -6.0.
- determinant([[1,2],[2,4]]) → 0.0, rank той же матрицы → 1.
- rank([[0,0],[0,0]]) → 0.
- norm1([[-1,2],[3,-4]]) → 6; count_nonzero([[0,2],[3,0]]) → 2.
- [], [[]], [[1],[2,3]], [[True]], [[NaN]], несовместимые размеры → ValueError.

Дополнительные свойства: T(T(A))=A, A+0=A, A*I=A, сумма входов не меняет ни один операнд. Не проверять коммутативность матричного умножения как общее свойство.

## Индивидуальные варианты

1. Протокол Гаусса. Для rank и determinant сохранять список обменов и вычитаний строк. Каждая запись содержит индексы и коэффициент. Проверить воспроизведение протокола на копии исходной матрицы.
2. Система уравнений. Реализовать solve(A,b) для квадратной невырожденной A. Для вырожденной поднять ValueError, не пытаться классифицировать все решения. Проверить остаток A*x-b с допуском и пример x=[1,2].
3. Степень матрицы. Реализовать power(A,k), k — целое 0..20, A квадратная. k=0 возвращает единичную. Сравнить последовательное и быстрое возведение по числу умножений.
4. Анализ таблицы. Дополнительно вычислять суммы строк, суммы столбцов, след квадратной матрицы и симметричность с допуском. На прямоугольной матрице след и симметричность отклонять. Проверить 1×1 и отрицательные элементы.
5. Пакет операций. Вход — список независимых запросов. Вернуть результаты в том же порядке с индексами, ошибка одного запроса не прекращает пакет. Проверить смешанный набор успешных и ошибочных запросов.
6. Численный эксперимент. На наборах матриц размеров 2,4,8,16 сравнить время matmul и исключения, 5 повторов на размер. Генерация вне измерения, seed фиксирован. Представить таблицу, график и ограничения вывода. Отдельно показать влияние eps на вычисленный ранг.

## Вопросы защиты

Как проверить неизменность входа? Как сложность зависит от m,n,p? Изменение на месте: добавить scale(A,k) с проверкой скаляра или трассировку выбора опоры.
