## Имена и значения

Переменная в Python — имя, связанное с объектом. Присваивание вычисляет правую часть, затем связывает результат с именем слева. Запись x=x+1 использует прежнее значение x при вычислении новой правой части. Имена total_cents и item_count показывают смысл данных лучше, чем a и b.

## Граница программы

input возвращает строку даже тогда, когда пользователь ввёл цифры. int преобразует запись целого числа в значение. Строка 12.5 не подходит для int. На этой неделе предполагаем корректный ввод; обработку исключений изучим отдельно. Формат ввода является частью контракта: два числа на одной строке и два числа на разных строках требуют разного чтения.

## Вывод и точность

Форматированная строка управляет отображением. Запись :.2f округляет только видимое представление. Сам объект float от этого не становится точным десятичным числом. Для учебного учёта денег используем целые копейки, а для физических измерений допускаем float и заранее обсуждаем точность результата.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/03.py` из корня комплекта.

```python
price_cents = 1250
count = 3
total = price_cents * count
print(f"{total // 100}.{total % 100:02d}")
assert total == 3750
```

1250 копеек умножаем на 3 и получаем 3750. Целая часть рублей 37, остаток копеек 50. Для остатка 5 формат :02d выдаст 05.

## Типичная ошибка

Сложение строк "2"+"3" даёт "23". Преобразование к числу требуется до вычисления.
