## Слияние

Если два списка уже отсортированы, наименьший оставшийся элемент находится в начале одного из них. Два указателя позволяют каждый элемент перенести ровно один раз. При равенстве выбираем левый элемент, чтобы сохранить стабильность. После исчерпания одного списка дописываем хвост другого.

## Разделение задачи

Сортировка слиянием делит список пополам, сортирует половины и сливает. На каждом уровне обрабатывается суммарно n элементов, уровней порядка log n. Для обычной реализации со списками время O(n log n), дополнительная память порядка n. Глубокие копии данных для слияния не нужны.

## Ограниченный диапазон

Если целые значения лежат в 0..k, можно подсчитать частоты и восстановить ответ. Время O(n+k), память O(k). Метод выгоден, когда диапазон разумно мал относительно n. Для двух значений 1 и 10^12 прямой массив частот не подходит. Встроенная sorted остаётся нормальным выбором в прикладном коде, если учебная цель не требует реализации алгоритма.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/20.py` из корня комплекта.

```python
def counting_sort(a, k):
    counts = [0] * (k + 1)
    for x in a:
        if type(x) is not int or not 0 <= x <= k:
            raise ValueError("вне диапазона")
        counts[x] += 1
    return [x for x in range(k + 1) for _ in range(counts[x])]

assert counting_sort([3, 0, 3, 1], 3) == [0, 1, 3, 3]
```

Массив частот [1,1,0,2] означает один 0, одну 1, ни одной 2 и две 3. Восстановление идёт по возрастанию индекса.

## Типичная ошибка

Для отрицательных значений без смещения Python интерпретирует индекс как отсчёт с конца, поэтому проверка диапазона обязательна.
