## Модель графа

Граф состоит из вершин и рёбер. Словарь списков соседей хранит только существующие связи и удобен для разреженных графов. В неориентированном графе каждое ребро записываем в обе стороны. Изолированную вершину тоже включаем с пустым списком, иначе она исчезает из модели.

## Слои обхода

Поиск в ширину использует очередь. Сначала обрабатываются вершины расстояния 0, затем 1, затем 2 и далее. В невзвешенном графе первое обнаружение вершины даёт кратчайшее расстояние по числу рёбер. Вершину отмечаем посещённой при добавлении в очередь, чтобы разные соседи не добавили её многократно.

## Восстановление пути

Сохраняем родителя, от которого впервые пришли в вершину. После достижения цели идём по родителям назад и разворачиваем список. При недостижимости возвращаем None, а для старта, совпадающего с целью, путь состоит из одной вершины. BFS не решает общую задачу кратчайшего пути с разными весами рёбер.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/27.py` из корня комплекта.

```python
from collections import deque
graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
distance = {"A": 0}
q = deque(["A"])
while q:
    v = q.popleft()
    for u in graph[v]:
        if u not in distance:
            distance[u] = distance[v] + 1
            q.append(u)
assert distance["D"] == 2
```

A обнаруживает B и C на расстоянии 1. B обнаруживает D на расстоянии 2. При обработке C вершина D уже посещена.

## Типичная ошибка

Если отметить посещение только после извлечения, одна вершина может появиться в очереди несколько раз.
