## Последовательность символов

Строка неизменяема. Индекс выбирает один символ, срез создаёт новую строку. Правый предел среза не включается. Индекс вне диапазона вызывает ошибку, тогда как срез допускает выход границ за длину. Поэтому s[:3] безопасен и для короткой строки, а s[2] требует проверки длины.

## Нормализация

Для сравнения без учёта регистра используем casefold. strip удаляет пробельные символы по краям, split без аргументов разделяет по группам пробельных символов. Ни один из этих методов автоматически не удаляет знаки пунктуации внутри слов. Правило о том, какие символы считаются буквами, должно быть частью задачи.

## Разбор формата

Для строки вида ключ=значение метод partition("=") отделяет первое вхождение разделителя. split("=") без ограничения может дать больше двух частей. Перед преобразованием проверяем структуру. Сначала разбираем текст, затем выполняем вычисления, затем форматируем ответ. Смешивание этих действий усложняет диагностику.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/07.py` из корня комплекта.

```python
s = "  Анна   ИВАНОВА  "
words = s.casefold().split()
normalized = " ".join(words)
assert normalized == "анна иванова"
assert "level" == "level"[::-1]
```

casefold меняет регистр, split превращает несколько пробелов в границы двух слов, join соединяет слова одним пробелом.

## Типичная ошибка

Замена s[0]="A" невозможна. Проверка палиндрома должна заранее определить судьбу пробелов и пунктуации.
