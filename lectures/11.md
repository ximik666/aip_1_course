## Уникальность

Множество хранит уникальные хешируемые элементы. Для пустого множества требуется set(), потому что {} создаёт словарь. Порядок обхода множества не является контрактом. Если нужен воспроизводимый вывод, преобразуем множество в отсортированный список.

## Операции

Пересечение A&B содержит общие элементы, объединение A|B — все элементы, разность A-B — элементы A, отсутствующие в B. Симметрическая разность A^B содержит элементы, принадлежащие ровно одному из множеств. Направление разности важно: списки пропусков и новых участников отличаются.

## Цена потери информации

Преобразование в множество удаляет повторения и сведения о позициях. Оно подходит для вопроса «встречалось ли значение», но не для подсчёта частот. Чтобы удалить дубликаты с сохранением первого появления, можно вести множество seen и отдельный результирующий список. Обе структуры решают разные части задачи.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/11.py` из корня комплекта.

```python
expected = {"a", "b", "c"}
arrived = {"b", "c", "d"}
assert expected - arrived == {"a"}
assert arrived - expected == {"d"}
assert expected & arrived == {"b", "c"}
```

Участник a ожидался, но не пришёл. d пришёл без регистрации. b и c есть в обеих группах.

## Типичная ошибка

Сравнение напечатанных множеств как строк ненадёжно. Проверять нужно сами множества или sorted(result).

## Совместная задача

База. Для двух списков вывести общие уникальные числа по возрастанию. [3,1,1,2] и [2,3,3] → [2,3].

Сначала запишите вход и выход, решите пример вручную и выделите граничный случай. Только после этого переходите к реализации.
