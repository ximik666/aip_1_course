## Выбор минимума

Сортировка выбором на шаге i находит минимум в хвосте и ставит его на позицию i. После шага префикс содержит наименьшие элементы в окончательном порядке. Число сравнений практически не зависит от исходной упорядоченности и равно n(n-1)/2.

## Вставка в префикс

Сортировка вставками сохраняет отсортированный префикс. Очередной элемент временно сохраняется, большие элементы сдвигаются вправо, затем значение вставляется на свободное место. На уже отсортированном входе достаточно линейного числа сравнений, в худшем случае число сдвигов квадратично.

## Стабильность

Стабильная сортировка сохраняет относительный порядок записей с одинаковым ключом. Во вставках условие строго больше сохраняет порядок равных значений. Замена на больше или равно может нарушить стабильность. Для чисел это незаметно, поэтому проверять свойство надо на записях с метками.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/19.py` из корня комплекта.

```python
def insertion_sort(values):
    a = list(values)
    for i in range(1, len(a)):
        x, j = a[i], i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x
    return a

assert insertion_sort([3, 1, 2, 1]) == [1, 1, 2, 3]
```

Префиксы для [3,1,2]: [3], затем [1,3], затем [1,2,3]. Сохранённое x не теряется при сдвиге.

## Типичная ошибка

Обмен первого найденного минимума с началом хвоста в сортировке выбором может переставить равные записи.
