## Ход занятия

- 0–10 минут: актуализация знаний и формулировка задачи.
- 10–30 минут: первый и второй разделы объяснения.

## Булевы выражения

Сравнение возвращает True или False. and требует истинности обоих условий, or — хотя бы одного, not меняет логическое значение. Выражение 0<=score<=100 прямо отражает допустимый диапазон. Короткое замыкание означает, что правая часть and не вычисляется, если левая ложна. Этим можно защитить деление: denominator!=0 and numerator/denominator>1.

## Выбор ветви

Цепочка if/elif/else выполняет первую подходящую ветвь. Несколько независимых if могут выполнить несколько действий. Для оценки по баллам проверяем пороги сверху вниз: сначала 85, затем 70, затем 60. Если начать с 60, студент с 90 попадёт в первую ветвь и не дойдёт до высшей оценки.

## Полнота случаев

Рисуем числовую ось и отмечаем интервалы. Каждый допустимый вход должен попадать ровно в одну категорию. Граничные тесты включают порог, значение непосредственно ниже и выше. Некорректный вход рассматриваем до классификации, иначе 150 баллов случайно станет отличной оценкой.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/04.py` из корня комплекта.

```python
score = 70
if not 0 <= score <= 100:
    result = "error"
elif score >= 85:
    result = "5"
elif score >= 70:
    result = "4"
elif score >= 60:
    result = "3"
else:
    result = "2"
assert result == "4"
```

При 70 проверка ≥85 ложна, проверка ≥70 истинна. Остальные ветви не выполняются. Вход 101 отсекается первой проверкой.

## Типичная ошибка

Условие x==1 or 2 всегда истинно: число 2 само имеет истинное логическое значение.

## Совместная задача

Сначала запишите вход и выход, решите пример вручную и выделите граничный случай. Только после этого переходите к реализации.
