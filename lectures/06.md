## Условие продолжения

while проверяет условие перед каждым выполнением тела. Если оно сразу ложно, тело не выполняется. Важно различать условие продолжения и условие остановки. Для накопления до достижения цели продолжаем, пока сумма меньше цели. После каждого шага должно меняться состояние, от которого зависит условие.

## Мера прогресса

Завершение удобно объяснять через целое неотрицательное значение, которое строго уменьшается. При разборе цифр положительного числа операция n//=10 уменьшает n. Значение 0 требует отдельного соглашения: у числа 0 одна цифра, хотя цикл while n>0 выполнится ноль раз. Сначала формулируем результат для этого входа.

## Сигнальное значение

Последовательность может завершаться специальным маркером. Маркер не является данными и не включается в сумму. Команда break немедленно завершает цикл, continue пропускает остаток текущей итерации. После continue также должен сохраняться прогресс: иначе обновление переменной может никогда не выполниться.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/06.py` из корня комплекта.

```python
n = 507
total = 0
while n > 0:
    total += n % 10
    n //= 10
assert total == 12
```

Состояния (n,total): (507,0), (50,7), (5,7), (0,12). Нулевая цифра не меняет сумму, но деление всё равно уменьшает n.

## Типичная ошибка

Условие n!=0 для отрицательного числа с //10 может привести к застреванию на -1. Для знаковых входов сначала берут abs.

## Совместная задача

База. Вычислить сумму цифр целого числа, включая отрицательные и 0. -507 → 12; 0 → 0.

Сначала запишите вход и выход, решите пример вручную и выделите граничный случай. Только после этого переходите к реализации.
