## Хранение последовательности

Список хранит упорядоченные ссылки на объекты. Элементы могут иметь разные типы, но однородные данные проще проверять. В Python есть и модуль array для типизированных числовых массивов, поэтому утверждение «массивов нет» неверно. В учебных алгоритмах под массивом часто подразумевают индексируемую последовательность на базе list.

## Изменение и копия

После b=a оба имени указывают на один список. append через любое имя изменяет общий объект. a.copy() создаёт новый внешний список, но вложенные объекты остаются общими. Для таблицы независимых строк нужна отдельная новая строка на каждой итерации, а не умножение списка, содержащего одну строку.

## Безопасное преобразование

Удаление элементов во время прямого обхода сдвигает оставшиеся индексы. Надёжнее построить новый список подходящих значений. Если контракт требует изменить исходный объект, можно присвоить срезу a[:] новый список. Это сохраняет идентичность контейнера и видимость изменения через другие ссылки.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/08.py` из корня комплекта.

```python
a = [1, 2]
b = a
c = a.copy()
b.append(3)
assert a == [1, 2, 3]
assert c == [1, 2]
clean = [x for x in [3, -1, -2, 5] if x >= 0]
assert clean == [3, 5]
```

Имена a и b связаны с одним объектом, c — с другой внешней последовательностью. Отрицательные элементы фильтруем в новый список.

## Типичная ошибка

Метод append возвращает None. Запись a=a.append(x) уничтожает связь имени a со списком.
