## Причина исключения

Исключение прерывает обычный поток и передаёт управление ближайшему подходящему обработчику. ValueError означает, что значение не подходит операции, TypeError — неподходящий тип. Ошибки индекса и имени часто указывают на дефект программы. Их не следует без разбора маскировать сообщением «неверный ввод».

## Уровень обработки

Вычислительная функция проверяет контракт и при нарушении поднимает определённое исключение. Интерфейс ловит ожидаемую ошибку и переводит её в понятное сообщение. Такой раздел делает одну функцию пригодной и для консольного приложения, и для тестов. Старые задания с возвратом строки error поддерживаем отдельным адаптером, если он нужен.

## Узкий обработчик

В try помещаем только операцию, ошибка которой ожидаема. except Exception вокруг всей программы скрывает слишком много причин. Если поддерживаются только конечные int и float, отдельно отвергаем bool, NaN и бесконечность. bool является подклассом int, поэтому isinstance(True,int) даёт True.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/13.py` из корня комплекта.

```python
def positive_int(text):
    value = int(text)
    if value <= 0:
        raise ValueError("нужно положительное число")
    return value

assert positive_int("12") == 12
try:
    positive_int("0")
except ValueError:
    pass
else:
    raise AssertionError("ожидали ValueError")
```

"12" проходит преобразование и проверку. "0" преобразуется успешно, но нарушает предметное ограничение. "abc" не проходит уже int.

## Типичная ошибка

Голый except также перехватывает прерывание пользователем. Исключения не должны превращаться в бесконечный повтор без сообщения.
