## Модель стоимости

Время на конкретном компьютере зависит от оборудования, реализации и входных данных. Асимптотическая оценка описывает рост затрат при увеличении n. O(n) — верхняя оценка линейного порядка в выбранной модели, а не точное число секунд. Указываем, что считаем элементарной операцией и какой параметр обозначает n.

## Последовательные и вложенные действия

Два последовательных прохода по n элементам дают линейный рост: n+n=2n. Два вложенных полных прохода дают n² пар. Если внутренний цикл начинается с i+1, число пар равно n(n-1)/2 и порядок остаётся квадратичным. Слово «вложенный» само по себе недостаточно: внутренний диапазон может быть константным.

## Память и случаи

Дополнительная память не всегда равна размеру входа. Сумма с одним накопителем требует O(1) дополнительной памяти, копирование списка — O(n). Для поиска различаем лучший случай, когда элемент первый, и худший, когда его нет. Оценку среднего случая можно давать только с предположением о распределении входов.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/17.py` из корня комплекта.

```python
n = 5
pairs = 0
for i in range(n):
    for j in range(i + 1, n):
        pairs += 1
assert pairs == n * (n - 1) // 2
```

Длины внутренних диапазонов: 4,3,2,1,0. Всего 10 пар. При удвоении большого n число пар приближается к увеличению в четыре раза.

## Типичная ошибка

O(1) означает независимость от размера рассматриваемого входа, а не мгновенное выполнение.
