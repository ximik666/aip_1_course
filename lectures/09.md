## Вход и результат

Функция получает аргументы и возвращает результат через return. print показывает текст пользователю и не заменяет return. Чистую вычислительную функцию можно вызвать из консоли, теста или другого модуля. Если функция всегда спрашивает input, автоматическая проверка становится зависимой от диалога.

## Область видимости

Имя, присвоенное внутри функции, обычно локально. Передача списка не создаёт его копию: изменение элементов затрагивает объект вызывающей стороны. В контракте нужно явно написать, изменяет ли функция вход. Для курса по умолчанию вычислительные функции возвращают новый результат и сохраняют переданные данные.

## Граничные результаты

Для среднего пустого набора нет обычного числового ответа. Можно вернуть None или поднять ValueError, но выбор должен быть единым для задания. Аннотации типов помогают читать контракт, однако сами не проверяют значения во время выполнения. Краткая строка документации описывает особые случаи и побочные эффекты.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/09.py` из корня комплекта.

```python
def mean(values):
    """Среднее или None для пустой последовательности."""
    if not values:
        return None
    return sum(values) / len(values)

assert mean([2, 4]) == 3
assert mean([]) is None
```

Пустой список возвращает None до деления. Для [2,4] числитель 6, знаменатель 2, результат 3.0.

## Типичная ошибка

Изменяемый аргумент по умолчанию values=[] создаётся один раз при определении функции и может накапливать данные между вызовами.
