## Перебор

for последовательно получает элементы объекта. range(start,stop,step) задаёт целые числа до stop, не включая его. range(1,5) даёт 1,2,3,4. Количество итераций следует выводить из последовательности, а не угадывать по записи. Отрицательный шаг позволяет двигаться в обратном направлении.

## Накопитель и инвариант

Для суммы нейтральное начальное значение равно 0, для произведения — 1. После каждой итерации total хранит сумму уже обработанных элементов. Это утверждение называют инвариантом. До первого шага обработанных элементов нет, и ноль действительно является их суммой. После последнего шага инвариант превращается в требуемый результат.

## Фильтрация при обходе

Условие внутри цикла позволяет учитывать только нужные элементы. Счётчик хранит число подходящих значений, сумма — их суммарный вклад. Если нужен средний результат, после цикла делим сумму на счётчик и отдельно обрабатываем счётчик 0. Не следует делить на общее число входов, если часть значений отброшена.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/05.py` из корня комплекта.

```python
total = 0
count = 0
for x in [3, -2, 0, 7]:
    if x >= 0:
        total += x
        count += 1
assert (total, count) == (10, 3)
```

После 3 состояние (3,1), после -2 оно не меняется, после 0 становится (3,2), после 7 — (10,3). Ноль участвует в количестве.

## Типичная ошибка

range(n) содержит n элементов, но последний равен n-1. Ноль нельзя исключать из неотрицательных значений.

## Совместная задача

База. Для n≥0 вычислить сумму квадратов от 1 до n циклом. 0 → 0; 3 → 14.

Сначала запишите вход и выход, решите пример вручную и выделите граничный случай. Только после этого переходите к реализации.
