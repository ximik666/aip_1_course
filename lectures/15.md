## Границы ответственности

В модуле domain.py находятся вычисления, в storage.py — работа с файлами, в main.py — диалог. При таком разделении ошибка ввода не меняет формулу, а смена формата хранения не требует переписывать расчёт. Не нужно создавать десятки файлов ради самого разделения: граница полезна, когда у частей разные причины изменяться.

## Импорт и запуск

Импорт выполняет инструкции верхнего уровня модуля. Поэтому интерактивный ввод под верхним уровнем блокирует импорт в тестах. Условие if __name__=="__main__" позволяет запускать диалог только при непосредственном выполнении файла. Не называйте свой файл json.py или random.py, иначе он может перекрыть стандартный модуль.

## Воспроизводимость

README описывает требуемую версию Python, команду запуска, формат данных и примеры. Изменения сохраняем небольшими осмысленными версиями. Для локального курса достаточно истории Git без публикации и аккаунтов. Файлы __pycache__ и временные результаты не относятся к исходному коду проекта.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/15.py` из корня комплекта.

```python
def total_cents(records):
    return sum(row["cents"] for row in records)

def main():
    print(total_cents([{"cents": 120}, {"cents": 80}]))

if __name__ == "__main__":
    main()
```

При запуске файла вызывается main и выводится 200. При импорте функция становится доступна тесту, но main не вызывается.

## Типичная ошибка

Импорт * скрывает происхождение имён. Круговые импорты часто показывают, что зависимости между частями выбраны неудачно.
