## Экземпляр и состояние

Класс задаёт устройство объектов, экземпляр хранит конкретные данные. self передаёт методам текущий объект. Два экземпляра должны иметь независимое состояние, если совместное хранение не задумано специально. Изменяемый список на уровне класса разделяется всеми экземплярами и часто становится ошибкой новичка.

## Инвариант объекта

Инвариант — условие, которое должно сохраняться после любой публичной операции. Для остатка товара это целое неотрицательное количество. Конструктор проверяет начальное состояние, метод выдачи отклоняет отрицательное число и нехватку остатка. Сначала все проверки, затем изменение: ошибка не должна оставлять объект наполовину обновлённым.

## Композиция

Приложение может содержать каталог, который содержит записи. Это композиция объектов. Наследование имеет смысл при настоящем отношении подтипа и совместимости поведения, а не только ради копирования пары методов. Для первого проекта предпочтительнее небольшой класс с ясным инвариантом, чем сложная иерархия.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/28.py` из корня комплекта.

```python
class Stock:
    def __init__(self, quantity):
        if type(quantity) is not int or quantity < 0:
            raise ValueError("неверный остаток")
        self.quantity = quantity
    def take(self, count):
        if type(count) is not int or not 0 <= count <= self.quantity:
            raise ValueError("нельзя выдать")
        self.quantity -= count

s = Stock(5)
s.take(2)
assert s.quantity == 3
```

После создания остаток 5, после выдачи 2 — 3. Попытка выдать 4 из остатка 3 должна завершиться ошибкой без изменения quantity.

## Типичная ошибка

Подчёркивание в имени обозначает соглашение о внутреннем использовании, а не абсолютную защиту от внешнего доступа.
