## Модель записи

Кортеж удобно использовать для небольшой позиционной записи, например пары координат. Словарь связывает уникальный ключ со значением и подходит для записи с именованными полями. Ключ должен быть хешируемым: строка и кортеж из чисел подходят, список — нет. Кортеж со списком внутри тоже не подходит.

## Частотный словарь

При подсчёте частот значение хранит число уже встреченных элементов с данным ключом. Метод get(key,0) задаёт нулевой счётчик для нового ключа. После обработки каждого слова увеличиваем только один счётчик. Так один проход превращает последовательность в сводку.

## Порядок и отсутствие

Словарь сохраняет порядок добавления ключей, однако это не означает автоматическую сортировку. Для отчёта в алфавитном порядке ключи сортируем явно. Отсутствующий ключ отличается от ключа со значением None. Метод get удобен, когда эти состояния можно объединить; оператор in нужен, когда различие существенно.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/10.py` из корня комплекта.

```python
counts = {}
for word in ["кот", "дом", "кот"]:
    counts[word] = counts.get(word, 0) + 1
assert counts == {"кот": 2, "дом": 1}
assert sorted(counts) == ["дом", "кот"]
```

После первого слова появляется кот:1, затем дом:1, затем значение кот изменяется на 2. Новый ключ на третьем шаге не создаётся.

## Типичная ошибка

Присваивание по существующему ключу заменяет прежнее значение. Одинаковые имена студентов нельзя использовать как уникальный идентификатор.

## Совместная задача

База. Подсчитать частоты целых чисел. [2,1,2,3,1,2] → {2:3,1:2,3:1}; [] → {}.

Сначала запишите вход и выход, решите пример вручную и выделите граничный случай. Только после этого переходите к реализации.
