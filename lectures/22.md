## Абстракция стека

Стек выдаёт последним добавленный элемент первым. list.append и list.pop с конца подходят для этой модели. Важен не только контейнер, но и разрешённые операции. Стек вызовов, отмена действий и незавершённые скобки используют одинаковый порядок вложенности.

## Сопоставление скобок

Открывающую скобку кладём в стек. Для закрывающей сначала проверяем, что стек не пуст, затем сравниваем с последней открывающей нужного типа. Несовпадение означает ошибку независимо от оставшегося текста. В конце стек должен оказаться пустым. Простого равенства количества открывающих и закрывающих недостаточно.

## Контракт текста

Нужно заранее решить, что делать с буквами и пробелами. В нашем примере они игнорируются. Поэтому алгоритм проверяет скобочную структуру текста, но не синтаксис Python: кавычки и комментарии не распознаются. Для полноценного языка нужен анализатор с другими правилами.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/22.py` из корня комплекта.

```python
def balanced(text):
    stack = []
    pairs = {")": "(", "]": "[", "}": "{"}
    for c in text:
        if c in "([{":
            stack.append(c)
        elif c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
    return not stack

assert balanced("a*(b+[c])")
assert not balanced("([)]")
```

В ([)] перед символом ) вершина стека равна [. Типы не совпадают, поэтому ответ False сразу, хотя числа скобок равны.

## Типичная ошибка

Чтение stack[-1] до проверки пустоты падает на строке, начинающейся закрывающей скобкой.
