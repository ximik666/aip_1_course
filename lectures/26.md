## Элементарные преобразования

Прибавление к одной строке другой, умноженной на число, сохраняет ранг. Перестановка строк также сохраняет ранг, но меняет знак определителя. Метод Гаусса последовательно создаёт нули под ведущими элементами. Число найденных ведущих элементов равно рангу в точной арифметике.

## Выбор опоры

Если диагональный элемент нулевой, алгоритм не обязан завершаться неудачей: можно найти ненулевую строку ниже и обменять строки. В вещественной арифметике выбирают наибольший по модулю элемент доступной части столбца. Это уменьшает опасность деления на слишком малое число, хотя не устраняет все проблемы численной устойчивости.

## Погрешность и контракт

Для учебных небольших матриц определяем порог eps, ниже которого элемент считаем нулевым. Абсолютный порог зависит от масштаба данных, поэтому результат около вырожденности может меняться при масштабировании. В проекте фиксируем диапазон входов и eps. Для квадратной матрицы после исключения без нормирования строк определитель равен произведению диагонали с поправкой знака перестановок.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/26.py` из корня комплекта.

```python
A = [[0.0, 2.0], [3.0, 4.0]]
A[0], A[1] = A[1], A[0]
sign = -1
determinant = sign * A[0][0] * A[1][1]
assert determinant == -6.0
```

В первом столбце опора 0, поэтому меняем строки. Получаем треугольную матрицу с диагональю 3,2. Из-за обмена определитель -6.

## Типичная ошибка

Если нормировать строку делением на ведущий элемент, произведение новой диагонали уже не равно исходному определителю без дополнительных поправок.
