## От текста к выполнению

Исходный файл содержит текст программы. Интерпретатор Python проверяет его синтаксис и выполняет инструкции. В интерактивном режиме выражения удобно исследовать по одному, а файл позволяет повторить весь опыт. В CPython исходный код обычно компилируется в байткод и выполняется виртуальной машиной. Поэтому деление языков на исключительно компилируемые и исключительно интерпретируемые слишком грубо.

## Типы и операции

int хранит целые числа, float — приближённые вещественные. Оператор / выполняет обычное деление, // — деление с округлением вниз, % — остаток. Для положительного делителя b выполняется a=(a//b)*b+a%b. В Python -7//3 равно -3, а не -2. Скобки явно фиксируют требуемый порядок вычислений.

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/02.py` из корня комплекта.

```python
a, b = -7, 3
q, r = a // b, a % b
print(q, r)
assert a == q * b + r
assert 2 + 3 * 4 == 14
```

Результат первой строки вывода: -3 2. Произведение -3*3 равно -9, добавление остатка 2 восстанавливает -7.

## Типичная ошибка

Знак ^ означает побитовое исключающее ИЛИ. Возведение в степень записывается **.
