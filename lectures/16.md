## Модель числа

Комплексное число a+bi представляем парой действительной и мнимой частей. При сложении складываем соответствующие компоненты. При умножении раскрываем скобки и используем i²=-1: результат (ac-bd)+(ad+bc)i. Для первого курса эта модель тренирует разложение задачи на небольшие функции.

## Деление

Умножение числителя и знаменателя на сопряжённое c-di даёт действительный знаменатель c²+d². Результат деления: ((ac+bd)/(c²+d²), (bc-ad)/(c²+d²)). Делитель нулевой только когда c=0 и d=0 одновременно. Внутренние вычисления не округляем до двух знаков: округление относится к показу пользователю.

## Демонстрация работы

Защита включает объяснение одного алгоритма, запуск обычного и ошибочного сценария, затем небольшое изменение на месте. В отчёте указываем не число строк кода, а контракт, выбранные проверки и ограничения. Полезный вопрос: почему тест с одинаковыми входами не заменяет тест с разными знаками компонентов?

## Пример с разбором

Перед запуском запишите ожидаемый результат или состояние. Затем выполните файл `examples/16.py` из корня комплекта.

```python
def multiply(a, b, c, d):
    return [a*c - b*d, a*d + b*c]

assert multiply(1, 2, 3, 4) == [-5, 10]
assert multiply(0, 0, 3, 4) == [0, 0]
```

(1+2i)(3+4i)=3+4i+6i+8i²=-5+10i. Нулевой множитель обнуляет обе компоненты.
