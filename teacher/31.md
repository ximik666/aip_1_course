# Ориентиры преподавателя к занятию 31

## Разбор

Проверка охватывает преобразование в JSON, запись, чтение и расчёт. Временный каталог удаляется после выхода из with.

## Ответы и ключевые шаги

Для матриц классы: обычная квадратная, прямоугольная, 1×1, нулевая, вырожденная, рваная, неверный тип, несовместимые размеры. Дополнительно проверить неизменность входа.

## Диагностика понимания

Попросите студента объяснить: Большое количество одинаковых тестов не заменяет покрытие разных контрактов. Нельзя объявлять проект корректным только по числу проверок.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
