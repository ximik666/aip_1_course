# Ориентиры преподавателя к занятию 27

## Разбор

A обнаруживает B и C на расстоянии 1. B обнаруживает D на расстоянии 2. При обработке C вершина D уже посещена.

## Ответы и ключевые шаги

Для коня минимальная длина 6 ходов. Представление клетки (строка,столбец), соседей фильтровать по границам 0..7.

## Диагностика понимания

Попросите студента объяснить: Если отметить посещение только после извлечения, одна вершина может появиться в очереди несколько раз.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
