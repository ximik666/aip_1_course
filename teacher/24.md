# Ориентиры преподавателя к занятию 24

## Разбор

Для n=3 вызовы 3,2,1,0. Возвращаемые значения 1,1,2,6. Умножение происходит при возврате.

## Ответы и ключевые шаги

Во вложенном списке для int возвращается само число, для list суммируются рекурсивные результаты. Контракт ограничивает допустимые типы и исключает циклические ссылки.

## Диагностика понимания

Попросите студента объяснить: Увеличение предела рекурсии не исправляет отсутствие базы и может создать дополнительный риск переполнения стека.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
