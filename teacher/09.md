# Ориентиры преподавателя к занятию 9

## Разбор

Пустой список возвращает None до деления. Для [2,4] числитель 6, знаменатель 2, результат 3.0.

## Ответы и ключевые шаги

Использовать items=None и создавать [] внутри. Для clamp достаточно min(hi,max(lo,x)).

## Диагностика понимания

Попросите студента объяснить: Изменяемый аргумент по умолчанию values=[] создаётся один раз при определении функции и может накапливать данные между вызовами.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
