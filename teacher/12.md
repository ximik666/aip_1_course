# Ориентиры преподавателя к занятию 12

## Разбор

DictReader использует первую строку как имена полей. Значение cents равно строке "120". Преобразование к int выполняется отдельно.

## Ответы и ключевые шаги

При записи использовать with open(path,"w",encoding="utf-8"). Проверить существование обязательных столбцов, а тип cents преобразовать явно.

## Диагностика понимания

Попросите студента объяснить: JSON с правильным синтаксисом может иметь неправильную структуру. Данные {"cents":"сто"} не становятся числом после загрузки.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
