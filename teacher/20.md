# Ориентиры преподавателя к занятию 20

## Разбор

Массив частот [1,1,0,2] означает один 0, одну 1, ни одной 2 и две 3. Восстановление идёт по возрастанию индекса.

## Ответы и ключевые шаги

Слияние использует два индекса и остаточные хвосты. Для сортировки слиянием базовый случай длина меньше 2.

## Диагностика понимания

Попросите студента объяснить: Для отрицательных значений без смещения Python интерпретирует индекс как отсчёт с конца, поэтому проверка диапазона обязательна.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
