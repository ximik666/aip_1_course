# Ориентиры преподавателя к занятию 30

## Разбор

Таблица для ступеней 0..5: 1,1,2,3,5,8. Каждый элемент использует только два уже вычисленных значения.

## Ответы и ключевые шаги

Для суммы t минимум берётся по best[t-c]+1 для c≤t. База best[0]=0. Сохранённая последняя монета позволяет восстановить набор.

## Диагностика понимания

Попросите студента объяснить: Динамическое программирование нельзя заменить жадным выбором без доказательства. Для монет 1,3,4 сумма 6 оптимальна как 3+3, а жадный выбор даёт 4+1+1.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
