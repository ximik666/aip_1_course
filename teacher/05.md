# Ориентиры преподавателя к занятию 5

## Разбор

После 3 состояние (3,1), после -2 оно не меняется, после 0 становится (3,2), после 7 — (10,3). Ноль участвует в количестве.

## Ответы и ключевые шаги

Делители 12: 1,2,3,4,6,12. Прямой алгоритм выполняет n проверок остатка. Для среднего нужны отдельные сумма и счётчик.

## Диагностика понимания

Попросите студента объяснить: range(n) содержит n элементов, но последний равен n-1. Ноль нельзя исключать из неотрицательных значений.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
