# Ориентиры преподавателя к занятию 19

## Разбор

Префиксы для [3,1,2]: [3], затем [1,3], затем [1,2,3]. Сохранённое x не теряется при сдвиге.

## Ответы и ключевые шаги

На возрастающем списке сдвигов 0, на убывающем из 20 элементов — 190. Считать сравнения с явным соглашением, включены ли проверки границы j.

## Диагностика понимания

Попросите студента объяснить: Обмен первого найденного минимума с началом хвоста в сортировке выбором может переставить равные записи.

Измените один вход из практики, попросите прогноз до запуска. Если результат получен копированием, предложите построить контрпример и исправить конкретную строку. Для заданий с несколькими реализациями оценивайте контракт и аргумент, а не совпадение текста кода с образцом.
